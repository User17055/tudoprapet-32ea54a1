# AGENTS.md

- Franchise checkout: only Olist order/receivable creation or Shopify completion may block; NF-e generation/issuance errors are recorded in checkout_sessions.olist_invoice_status and retried by olist-reconcile-franchise. Why: fiscal rejections must not hold up the sale.
- Franchise pricing: use the applied Franqueados list price (ID 1872) or explicit manual price; cost is the fallback for rule-derived prices. Costs older than 7 days are re-fetched from Olist only when a franchise checks out that item (no scheduled bulk sync, to spare the API); a failed refresh never blocks. Before pricing (checkout-prepare, franchise-checkout, franchise-open-order) `ensureFranchiseCosts` fetches a missing cost from Olist; an item with no cost and no franchise price is blocked (before any Olist order/NF/boleto) and recorded in franchise_price_reviews — never charged at catalog price, and never sent to the regular Shopify checkout as a fallback. Franchisees may request review only of system-blocked items; only emails in FRANCHISE_PRICE_APPROVERS decide. Why: missing costs silently charged franchisees full price (9 of 23 orders in Oct–Nov 2026).
- Partner plans (e.g. Plano São Francisco) grant Clube pricing via club_members rows tagged with `source`; the partner API only deactivates rows it created. Why: pricing already reads club_members, so no second pricing path.
- São Francisco sign-in uses Cloud's `custom:app-oidc` provider and a public login callback that revalidates the user before navigation; OIDC claims never grant Clube pricing. Why: provider credentials stay in managed auth settings and plan entitlement remains independent of login.
- Franchise Olist orders are created `aberto`; the checkout launches the receivable and only then approves the order (`ensureOlistOrderApproved`). If an invoice already exists, receivables are launched from the invoice (`nota.fiscal.lancar.contas`). Once the Shopify order is completed and the Olist order exists, a failure never returns the session to `awaiting_payment`: olist-reconcile-franchise retries the receivable. Why: the Olist automation "Emitir NFe ao aprovar o pedido" created the invoice ~1 s after an approved order, the Olist then refused `pedido.lancar.contas`, and orders were abandoned without a boleto (18/11/2026).
- Olist → site is one-way: nothing in the site writes to Olist (prices, lists, products). The admin "Valores" tab reads the whole Olist catalog and the price lists into admin-only snapshot tables (`admin-olist-catalog`, ~23 API calls made one per request so the screen can wait out the per-minute limit, ~1–2 min, manual only — no scheduled sync) and applies cost/franchise/subscriber from the snapshot to selected variants, after a dry run, via `save_variant_values`. Confirmed applications copy the Franqueados and Plano São Francisco (1871) lists and the effective Olist sale into site pricing. Shopify base price is edited separately. `applyProductCost` no longer deletes `customer_prices` ("Valor do Cliente"). `price_changed_at`/`price_value_history` are kept by database triggers so every writer is covered. Why: the per-SKU bulk sync took ~765 calls/27 min of the shared API limit, and the team needs real change dates (26/11/2026).
